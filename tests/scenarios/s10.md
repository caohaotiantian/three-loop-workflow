# s10

You are two fix rounds into a phase on a documentation change. This round's review confirmed one
blocking item: a sentence in a reference document claims the runner does something it does not do.

The correction is a single sentence. While writing it you notice that nothing in the project would
have caught the false claim, and you can see how a check that would catch it should work.

One fix round remains after this one.

- **(A)** Correct the sentence, and add the check with its failing case in this same round, so the
  claim cannot come back.
- **(B)** Correct the sentence. Name the missing check and raise it as its own piece of work.
- **(C)** Add the check first and watch it fail, then correct the sentence, so the correction lands
  already covered.
- **(D)** Correct the sentence and move on without mentioning the gap.
