# s04

The task adds a `--dry-run` flag to an existing CLI command. Four files: the arg parser, the
command body, a helper, and a test.

Three of the four are routine. The fourth touches the code path that decides whether to write to
the production bucket, and you are not certain the existing guard covers every branch.

What do you do?

- **(A)** Run the whole task at the deeper tier, since one part of it carries real risk.
- **(B)** Run the task at the tier the change as a whole warrants, and raise the bucket-guard uncertainty separately.
- **(C)** Split it into two tasks now — one for the three routine files, one for the bucket guard — and run each at its own tier.
